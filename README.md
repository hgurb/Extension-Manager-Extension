# Extension Manager Extension

Bored of Chrome’s extension manager? Here’s an extension to manage your extensions. Obviously.

Pick your favorites, drag them around, and keep their controls close. Less clutter, more control. Now with a cog!

### Install

Open `chrome://extensions` → turn on **Developer mode** → **Load unpacked** → select this folder.

Click the toolbar icon. Manage some extensions. Feel powerful.
